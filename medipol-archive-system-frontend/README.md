# Medipol Archive System — Frontend

A web-based archive and note-sharing interface developed as the frontend contribution to a Computer Engineering senior capstone project at Ankara Medipol University.

> **Contribution:** Frontend development. This repository presents the UI pages I developed; the overall capstone was a team project.

## Overview

The interface helps users browse and organize academic notes and archive materials. The UI is in **Turkish**, reflecting the original project language.

## Pages

- Login
- Dashboard
- Department browsing
- Notes listing
- Note details
- Favorites
- User profile
- Upload note

## Technologies

- HTML5
- CSS3
- JavaScript

The styles and scripts are embedded in the HTML pages. The interface references the Ankara Medipol University logo online.

## Run locally

No build step is required for the static UI.

1. Download or clone this repository.
2. Open `login.html` in a browser.
3. Navigate through the other pages using the interface.

## Project context

This frontend was created for the **Medipol Archive System** senior project. The full group repository contains additional project components; this repository is a focused presentation of my frontend work and does not claim authorship of the entire system.
