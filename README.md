# Medipol Archive System — Frontend

A web-based archive and note-sharing application developed as part of a Computer Engineering senior project at Ankara Medipol University.

## Project Overview

The Medipol Archive System is designed to help university students browse, organize, and share academic notes and educational materials.

This repository showcases my **frontend development contribution** to the group project.

The user interface is in Turkish, reflecting the original language of the application.

## My Contribution

I was responsible for developing the frontend interface, including the following pages:

- Login Page
- Dashboard
- Department Page
- Notes Page
- Note Detail Page
- Favorites Page
- User Profile Page
- Upload Note Page

I focused on creating a consistent and user-friendly interface across the application's different sections.

## Run Locally

This is a static frontend project.

1. Clone the repository.
2. Open `login.html` in your browser.
3. Navigate through the application's pages.

No additional build tools are required to view the static interface.
